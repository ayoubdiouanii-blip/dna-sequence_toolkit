# DNA Sequence Toolkit 

A beginner Python project exploring basic bioinformatics operations.

## Features

- Count A, T, G, and C nucleotides
- Calculate GC content
- Generate the complementary DNA strand
- Detect invalid characters in a DNA sequence
- Convert a coding DNA sequence into RNA

## Technologies

- Python

## What I Learned

This project helped me practice Python strings, loops, conditional statements, and basic DNA sequence analysis.

## Status

Learning project — new features will be added as I develop my Python and bioinformatics skills.
